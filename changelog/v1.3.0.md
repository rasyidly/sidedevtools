# v1.3.0 — 2026-10-24

Adds four new tools, a region-capture workflow shared across the QR and color tools, and a reworked background-remover runtime that works under the extension CSP.

## Added

### Tools

- **Color & Palette Toolkit** (new *Design* category) — Tailwind v4-first color workbench with OKLCH as the default output.
  - Convert between HEX, RGB, HSL, HSV, OKLCH and OKLAB.
  - Generate 50–950 ramps with configurable shade steps, hue shift, chroma curve and neutral pairing.
  - Sample pixels with the OS EyeDropper or by dragging a box over the page, and extract dominant palettes from any image with OKLab k-means.
  - Find the nearest named and Tailwind color, explore harmony sets, and audit WCAG 2.2 plus APCA contrast with pass/fail badges.
  - Export Tailwind `@theme` blocks, CSS variables, JSON or hex lists.
- **QR & Barcode Reader** — decode QR, Data Matrix, Aztec, PDF417, Code 128/39/93, Codabar and EAN/UPC codes by capturing a region of the page, uploading an image, pasting or dropping a file. The *Generate* tab builds stylable QR codes for text, URLs, WiFi, contacts, email, SMS, phone, geo and OTP payloads, with PNG/SVG download and payload copy.
- **Regex Playground** — live match highlighting, flag toggles, per-match numbered and named capture groups, a plain-English explanation of every token (nested groups included), replacement preview, and a library of common patterns.
- **Form Filler & Auto-Recognize** — opt-in, gesture-driven form filling.
  - Focus any input and press **⌘ + double-click** to fill it, or **⌘ + Shift + double-click** to fill the whole form.
  - Recognizes fields from `autocomplete`, input type, `name`, `id`, placeholder and label — 20+ field kinds including email, phone, address, card number, CVV, password, dates and prices, in English or Indonesian.
  - Configurable modifier key, language, per-kind pattern overrides, "only fill empty fields", select menus, in-page confirmation and per-site pausing.
  - Values come from the bundled seeded `@faker-js/faker` engine; no network calls.

### Platform

- Shared drag-to-select region capture used by the TOTP scanner, QR & barcode reader and color toolkit.
- Barcode encode/decode library covering 1D and 2D symbologies.
- `pnpm verify` script that exercises the color toolkit, regex tester and faker/form-filler engines headlessly.

## Changed

- Keyboard shortcut is now **⌘ + Shift + S** (`Ctrl + Shift + S`) instead of `⌘ + Shift + D`.
- TOTP QR scanning now uses drag-to-select region capture on the page rather than the previous screen-scanning flow.
- Background service worker now reconciles the Form Filler content-script registration on install, browser startup and worker wake-up, so the toggle state survives reloads.
- Background remover serves `onnxruntime-web` assets from the extension origin, pairing the `.mjs` glue and `.wasm` binary from the same local build instead of mixing local glue with the CDN binary.
- Build runs a second Vite pass (`vite.content.config.ts`) that bundles the Form Filler content script into a self-contained IIFE `content.js`, since Chrome injects content scripts as classic scripts.
- New Vite plugin swaps `ndarray`'s generated-code path for a CSP-safe, eval-free implementation when bundling `@imgly/background-removal`.
- Tool registry, manifest description and docs updated for the new tools and shortcut; extension version bumped to `1.3.0`.

## Fixed

- Background remover failed at WASM instantiation with `H._a is not a function` when the local `.mjs` glue was paired with a differently-configured CDN `.wasm`.
- Background remover could break under the extension content security policy because of `eval` usage inside `ndarray`; the CSP-safe replacement now applies in both build and dev.

## Upgrade notes

- Reload the unpacked extension after updating so the new shortcut and content script are registered.
- If Form Filler was enabled before the update, confirm the toggle is still on; the worker re-registers the content script automatically once enabled.
