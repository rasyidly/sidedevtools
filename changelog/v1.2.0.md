# v1.2.0 — 2026-10-19

Initial release of **SideDevTools**, a privacy-first developer companion that lives in Chrome's side panel. Everything runs locally in the browser sandbox.

## Added

### App shell

- Chrome Manifest V3 extension with a native side panel (`chrome.sidePanel`), openable from the toolbar action or with **⌘ + Shift + D** (`Ctrl + Shift + D`).
- Tool home grid with instant `/` search, category filters, tag filtering, and pinned favorites at the top.
- Sidebar header for quick tool switching and a recent-tools list.
- Shopify Polaris-inspired design tokens with Geist Sans/Mono typography, plus light and dark themes that follow the OS.
- About & support modal.

### Tools

- **Password Generator & Vault** — cryptographically secure passwords with length and character-set controls, entropy meter, crack-time estimates, and an offline vault with JSON backup export/import.
- **TOTP Authenticator & QR Scanner** — real-time 2FA codes with countdown, accounts added by scanning the active tab, uploading an image, pasting from the clipboard, or entering a secret manually.
- **Hash & Checksum Generator** — MD5, SHA-1, SHA-256 and SHA-512 digests with instant comparison against an expected value.
- **Encode / Decode Suite** — Base64 (UTF-8 and URL-safe), URL encoding with query-parameter breakdown, HTML entities, binary/hex streams, and a JSON Web Token inspector with claims and expiry.
- **Universal ID Generator** — batched UUID v4, UUID v7, ULID, NanoID, CUID2 and Unix timestamps with custom prefix, suffix and casing.
- **HTTP Request Converter** — translate requests between cURL, `fetch`, Axios, Python Requests, Go, Rust and Node.js.
- **Document to Markdown (AnyDoc)** — locally converts `.docx`, `.pdf`, `.pptx`, `.xlsx`, `.csv`, `.epub` and `.rtf` into GitHub-Flavored Markdown through WebAssembly.
- **Tab Storage & Session Manager** — inspect, search, edit and export `localStorage`, `sessionStorage` and cookies for the active tab.
- **Meta Tags & OpenGraph Inspector** — audit page SEO metadata and preview Google, Facebook and X social cards.
- **JSON Formatter & Validator** — prettify, minify and validate JSON with syntax error locations and object metrics.
- **Any DateTime Parser & Formatter** — convert between Unix epochs, ISO 8601, UTC, SQL strings, Excel serial numbers and timezones, including natural-language input.
- **AI Background Remover** — on-device background removal via `@imgly/background-removal` and `onnxruntime-web`; paste or drop an image to download a transparent PNG.
- **Favicon & App Icon Generator** — multi-resolution `favicon.ico`, Apple touch icons, Android PWA assets, `site.webmanifest` and a ready-to-download `.zip`.

## Notes

- No analytics, telemetry or remote processing: vault entries and settings are stored in local browser storage only.
- The extension requests `<all_urls>` host access so page-inspection tools can read the active tab on demand.
